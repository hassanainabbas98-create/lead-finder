OpenStreetMap Data & Attribution

Business Opportunity Finder discovers physical business entities using open data provided by OpenStreetMap (OSM) and accessed via community Overpass API endpoints.

OpenStreetMap Attribution:
Data is © OpenStreetMap contributors, made available under the Open Database License (ODbL).
Responsible Usage & Politeness:
  • We respect community Overpass API servers by utilizing rotating mirror servers, client-side rate-limiting, and cached responses.
  • We do not scrape Google Maps web pages or bypass external access restrictions.
  • Search results are limited to sensible batch counts to prevent server strain.
Prospecting Realities & Limitations
Coverage Varies by City and Country

OpenStreetMap coverage depends on community volunteer mapping. Some cities (e.g. Lahore, Dubai, London) have active mapping communities with thousands of listings, while other regions may have sparse records. The application cannot guarantee all businesses in a city will be found.

"No Website Listed" vs "Has No Website"

When a record shows No Website Listed, it means the OpenStreetMap contributor did not tag a website URL for that entity. It does not definitively prove the business has no web presence. Similarly, an inaccessible website during checking does not imply the company lacks an online presence permanently.

Detection Caveats (Chatbots & Voice Agents)

The website audit inspects public HTML for common chat scripts and booking widgets. A status of Not Detected means no known widget signatures were found; custom or unlisted tools might still be active. Furthermore, AI voice agents cannot be detected via website scraping.

Ethical Outreach & Privacy

Only public business contact details (business phone numbers, official inquiry emails) are retrieved. Users are responsible for complying with local regulations (such as CAN-SPAM, GDPR, and anti-telemarketing rules) when reaching out to prospective clients.

Architecture Overview
Backend: FastAPI with Python 3.12 & Uvicorn
Frontend: Jinja2 templates, Bootstrap 5.3, Bootstrap Icons, Vanilla JS
Database: SQLite with SQLAlchemy 2.0 ORM
Discovery Layer: Overpass API with multi-endpoint fallback
Security: SSRF guard with private IP range blocking & safe CSV formula escaping
Designed for 100% local Windows execution without requiring Docker, cloud databases, or paid API keys.
